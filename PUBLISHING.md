# Publish NOOR on GitHub Pages

1. Sign in to https://github.com and create a new **public** repository named `noor-study-hub`. Do not add a README when creating it.
2. On the repository page, click **Add file → Upload files**. Upload **the contents** of this folder (index.html, assets/, data/, resources/, .nojekyll, etc.), not the ZIP and not a surrounding NOOR folder. If your browser upload misses .nojekyll, the site should still work without it.
3. Commit changes. Open **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**; branch `main`, folder `/ (root)`; Save.
4. Wait for GitHub Pages to finish publishing. Visit `https://YOUR-USERNAME.github.io/noor-study-hub/` (replace YOUR-USERNAME).

Important: Public GitHub Pages sites are publicly accessible. Your in-browser additions, study plan and progress remain in that browser only, and won't sync between iPad and laptop. The packaged study PDFs and quizzes are public once uploaded. Do not upload private notes.
